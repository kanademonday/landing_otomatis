Pemeriksaan data

Ke AutoCAD

  1. Di AutoCAD Map 3D, klik kotak command line di bawah.
  2. Tekan Ctrl+V. Polyline bidang langsung tergambar di koordinatnya.
  3. Bila bidang tidak terlihat, ketik Z Enter lalu E Enter (zoom extents).
  4. Bila yang muncul malah tulisan perintah, tekan Ctrl+Z di AutoCAD, klik dulu command line, lalu Ctrl+V lagi.
Lihat isi yang disalin

Alternatif bila salin-tempel tidak bisa: buka atau INSERT file DXF di AutoCAD, lalu Save As DWG. Berisi bidang, nomor titik, label luas, bidang lain, jalan dari gambar, dan bingkai gambar.
