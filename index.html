Pengaturan baca otomatis (AI)

AI membaca isian (luas, skala, kelurahan, jalan) dan menelusuri gambar. Hasilnya selalu perlu diperiksa, terutama tulisan tangan.

  1. Buka console.groq.com/keys, masuk dengan akun Google.
  2. Klik Create API Key, salin kuncinya ke kotak di atas.
  3. Kunci hanya disimpan di browser ini. Tiap anggota tim sebaiknya memakai kunci sendiri, karena batas gratisnya dihitung per akun.

Gratis dengan batas pemakaian per menit/hari; bila penuh, aplikasi menunggu lalu mencoba lagi. Menurut ketentuan Groq, data tidak dipakai untuk melatih AI dan tidak disimpan secara bawaan.

Pemeriksaan data

Ke AutoCAD

  1. Di AutoCAD, tekan Esc dua kali agar tidak ada perintah yang sedang berjalan.
  2. Klik kotak command line di bagian bawah (bukan area gambar).
  3. Tekan Ctrl+V, lalu Enter satu kali. Polyline langsung tergambar di koordinatnya. (Enter kedua akan mengulang perintah PLINE; tekan Esc bila itu terjadi.)
  4. Bila tidak terlihat, ketik Z Enter lalu E Enter.
Lihat isi yang disalin

Alternatif bila salin-tempel tidak bisa: buka atau INSERT file DXF di AutoCAD, lalu Save As DWG. Berisi bidang, nomor titik, label luas, bidang lain, jalan dari gambar, dan bingkai gambar.
